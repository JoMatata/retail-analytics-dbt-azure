# Kenya Retail Sales Analytics

dbt project for a **fictional** Kenyan multi-channel retailer (web, app, physical stores).
All data is synthetic, generated by `scripts/generate_data.py`.

**Layers**

| Layer | Schema | Purpose |
|---|---|---|
| sources | `raw` | CSVs as landed in Azure Blob / ADLS Gen2, all text |
| staging (`stg_*`) | `staging` | 1:1 with sources: dedupe, type, normalise casing / phone / payment method |
| intermediate (`int_*`) | `intermediate` | enriched order lines, payment roll-ups, customer order sequence |
| marts | `marts` | `fct_orders` (incremental), dims and business marts consumed by Tableau |

Revenue = net of promo discounts, **completed orders only** (cancelled and returned excluded).
